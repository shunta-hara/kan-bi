---
description: 指定したファイル・モジュールに対する Vitest テストを作成する
---

対象: $ARGUMENTS

以下の手順でテストを作成してください。

1. 対象ファイルを読み、責務（純粋関数 / Server Action / Route Handler / React コンポーネント）を判別する
2. `@.claude/rules/testing.md` の方針に従い、テストファイルを `__tests__/` または対象と同階層の `*.test.ts(x)` に作成する
3. 以下を必ず含める:
   - 正常系（典型的な入力で期待通りの結果になる）
   - 異常系（不正な入力・外部APIエラー・owner不一致など）
   - 境界値（空配列、上限値、型推論の揺れなど）
4. 外部依存（Google Sheets API, Upstash Redis, Prisma）は Vitest のモック（`vi.mock`）で差し替え、実サービスへ接続しない
5. `pnpm vitest run <作成したテストファイル>` を実行し、全件パスすることを確認する
6. 失敗した場合は原因を特定し、テストまたは実装側のどちらに問題があるかを明示した上で修正する

完了したら作成したテストファイルのパスと、検証した正常系・異常系・境界値の概要を報告してください。
